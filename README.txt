HENRY REISSIG GIS & GEOGRAPHY PORTFOLIO

OPEN ON YOUR COMPUTER
1. Extract the entire ZIP (do not open files inside the ZIP).
2. Open index.html in Edge, Chrome, or Firefox.
3. Select a project to read its documents on the page.
Keep the folders together so images, reports, and video continue to work.

PUBLISH WITH GITHUB PAGES
1. Upload every extracted file and folder to your repository root.
2. Keep index.html in the root, alongside style.css and script.js.
3. In GitHub: Settings > Pages > Deploy from a branch.
4. Choose your main branch and / (root), then Save.

EDIT CONTENT
Project content is in projects.js. projects.json is a reference copy.
Appearance is in style.css. The reader is viewer.html, viewer.css, viewer.js.
Document page images are in pages/ and metadata is in documents.js.
The existing PDFs, Word documents, presentations, and video are in materials/.
The professional project inventory contains summaries where no map/report was submitted.

No installation or external online document viewer is required.
